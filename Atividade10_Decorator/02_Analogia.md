# Exercício 2 – Analogia

Crie uma analogia própria para explicar o padrão Decorator para alguém que não é da área de TI.

Na aula, usamos a pizza montada: a massa é a base, os ingredientes são adicionados por cima, e no fim continua sendo uma pizza, só que "decorada". Agora crie uma outra analogia.

## Perguntas

Descreva uma situação do mundo real em que:
- exista um objeto base que pode receber acréscimos opcionais, combináveis e empilháveis,
- cada acréscimo não muda o que o objeto é, apenas soma algo a ele (mantendo o "mesmo tipo" de coisa),
- e combinar acréscimos por duplicação antecipada (uma versão para cada combinação) seja inviável.

*Resposta:*
Um carro alugado com opcionais seria uma boa analogia. O carro base é o carro alugado normal, e da pra ir adicionando opcionais tipo GPS, cadeira de bebe, seguro extra, e cada um desses so soma uma coisa a mais no carro, sem virar outro tipo de veiculo, continua sendo um carro alugado. Se a locadora tivesse que ter um carro cadastrado pra cada combinacao possivel de opcionais ia ser inviável, por isso cada opcional entra em cima do carro base em vez de duplicar carro pra cada combinacao.
